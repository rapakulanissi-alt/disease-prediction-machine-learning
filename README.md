# Disease Prediction Using Machine Learning

## Project Description

This project predicts diseases based on symptoms using a Machine Learning model.

The project uses Python, Pandas, Scikit-learn, Joblib and Streamlit.

## Project Structure

- app/app.py - Streamlit web application
- data/disease_data.csv - Dataset
- models/disease_model.pkl - Trained Machine Learning model
- src/train_model.py - Model training code
- src/predict.py - Disease prediction code
- requirements.txt - Required Python libraries

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
